> 対象：v0.3.0

土台の値を文字で表示するフィルタ効果です。

## 項目

| 項目 | 内容 |
|---|---|
| テキスト | 表示する文。`{` と `}` で囲んだ部分を計算式として計算し、結果に置き換えます。既定は `{値1}` |
| 小数の扱い | 計算結果の書き方。「四捨五入」（既定）、「切り捨て」、「小数第1位まで」、「小数第2位まで」 |
| 桁数 | 整数部分がこの桁数に満たないとき、前を 0 で埋めます。「しない」（0）なら埋めません。10 桁まで |
| サイズ〜I | 文字の大きさ・字間・行間・フォント・色・文字装飾・太字・斜体。AviUtl2 の「テキスト」と同じです |
| X / Y / 拡大率 | [連番スロット](連番スロット) と同じ |

## テキストの例

| テキスト | 表示（値1 が 80、値2 が 3 のとき） |
|---|---|
| `HP {値1} / 100` | HP 80 / 100 |
| `残り {値2 - 1} 回` | 残り 2 回 |

`{ }` の中の書き方は [計算式の書き方](計算式の書き方) と同じです。

## 小数の扱い

`{値1 / 3}` のように割り算をすると、結果に小数が出ます。「小数の扱い」で、どこまで見せるかを選びます。

| テキスト | 小数の扱い | 表示（値1 が 100 のとき） |
|---|---|---|
| `{値1 / 3}` | 四捨五入 | 33 |
| `{値1 / 3}` | 小数第1位まで | 33.3 |
| `{値1 / 6}` | 切り捨て | 16 |
| `{値1 / 6}` | 四捨五入 | 17 |
| `{値1 / 6}` | 小数第2位まで | 16.67 |
| `{値1 / 20}` | 小数第1位まで | 5.0 |

- 「小数第1位まで」「小数第2位まで」は、その桁まで四捨五入します。`5.0` のように、端数の 0 も表示します。
- 「切り捨て」は、0 に近いほうへ切り捨てます（-16.7 は -16）。
- 「四捨五入」は、ちょうど半分のとき 0 から遠いほうへ丸めます（2.5 は 3、-2.5 は -3）。

## 桁数（ゼロ埋め）

スコアやタイマーで、`007` のように桁をそろえたいときは、「桁数」を指定します。

| テキスト | 小数の扱い | 桁数 | 表示（値1 が 100 のとき） |
|---|---|---|---|
| `{値1 / 20}` | 四捨五入 | 3 | 005 |
| `{値1 / 8}` | 小数第1位まで | 3 | 012.5 |
| `{値1 * -7 / 100}` | 四捨五入 | 3 | -007 |
| `{値1}` | 四捨五入 | 2 | 100 |

- 埋めるのは整数部分だけです。小数の部分や、負の符号は数えません。
- 桁数より長い数は、そのまま全部表示します。

## 注意

- 小数の扱いと桁数は、テキストの中のすべての `{ }` に同じように掛かります。`HP ` のような地の文には掛かりません。
- とても大きな数（9007199254740992 より大きい数）は、`1e+20` のような書き方になります。小数の扱いと桁数は掛かりません。
