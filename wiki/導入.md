> 対象：v0.3.0

## 動作環境

- AviUtl ExEdit2 v2.1.17 以降

## AviUtl2 カタログから入れる（おすすめ）

[AviUtl2 カタログ](https://github.com/Neosku/aviutl2-catalog) は、AviUtl2 のプラグインやスクリプトを、検索・インストール・更新・削除できるアプリです。

1. AviUtl2 カタログを起動します。
2. 「連番まとめ」を検索して、インストールします。
3. AviUtl2 を起動すると、「オブジェクト追加」と、フィルタ効果の [+] に「連番まとめ」が出ます。

新しい版が出たときは、AviUtl2 カタログから更新できます。消すときも、AviUtl2 カタログから削除します。

## ドラッグ＆ドロップで入れる

1. [Releases](https://github.com/osakanamaki/renban-matome/releases/latest) から、`renban-matome-vX.Y.Z.au2pkg.zip` をダウンロードします。
2. zip を展開せずに、AviUtl2 のプレビュー画面にドラッグ＆ドロップします。
3. 「オブジェクト追加」と、フィルタ効果の [+] に「連番まとめ」が出ます。

Script フォルダの下の `連番まとめ` フォルダに入ります。
消すときは、「その他」メニューの「パッケージ情報」から、アンインストールできます。

新しい版に入れ替えるときも、同じようにドラッグ＆ドロップします（前の版は消えてから入ります）。

## 手で入れる

1. [Releases](https://github.com/osakanamaki/renban-matome/releases/latest) から `renban-matome-vX.Y.Z.au2pkg.zip` をダウンロードして、展開します。
2. 展開した中の `Script\連番まとめ` フォルダを、AviUtl2 の Script フォルダ（例：`C:\ProgramData\aviutl2\Script`）に置きます。
3. AviUtl2 を起動し直すと、「オブジェクト追加」と、フィルタ効果の [+] に「連番まとめ」が出ます。

`連番まとめ` フォルダの中身：

| ファイル | 部品 |
|---|---|
| `連番まとめ（値）.obj2` | 土台 |
| `連番スロット.anm2` | 連番スロット |
| `連番スロット（ゲージ）.anm2` | 連番スロット（ゲージ） |
| `静止画スロット.anm2` | 静止画スロット |
| `連番スロット（計算式）.anm2` | 連番スロット（計算式） |
| `テキスト数値スロット.anm2` | テキスト数値スロット |
| `連番スロット（複製並べ）.anm2` | 連番スロット（複製並べ） |
| `LICENSE.txt` | ライセンス（MIT License） |

フォルダの名前は変えてもかまいません。スクリプトのファイル名を変えても動きます。

## 最初の一歩

1. 「オブジェクト追加」→「連番まとめ」→「連番まとめ（値）」を置きます。
2. オブジェクト設定の [+] →「連番まとめ」から「連番スロット」を追加し、「画像」に連番の画像（例：`hp_000.png`）を指定します。
3. 土台の「値1」を動かすと、画像が切り替わります。

続きは [連番まとめ（値）](連番まとめ（値）) と [連番スロット](連番スロット) を見てください。
