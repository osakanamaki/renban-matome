> 対象：v0.3.0

[連番スロット（計算式）](連番スロット（計算式）) の「計算式」と、[テキスト数値スロット](テキスト数値スロット) の `{ }` の中で使う書き方です。

## 使えるもの

| 種類 | 書き方 |
|---|---|
| 土台の値 | `値1`〜`値8`（小数点以下は切り捨てた値） |
| 数 | `2`、`0.5` など |
| 計算 | `+ - * / % ^` |
| 比較 | `< > <= >= == ~=` |
| 論理 | `and` `or` `not` |
| 括弧 | `( )` |
| 数学の関数 | `math.abs` `math.ceil` `math.floor` `math.fmod` `math.max` `math.min` `math.sqrt` |
| 数学の定数 | `math.pi` `math.huge` |

これ以外の名前や記号（`" ' [ ] { } ;`）を含む式は、計算せずに案内を出します。

## 使えるものを絞っている理由

計算式は、プロジェクトファイル（.aup2）に保存されます。
共有された .aup2 に、ファイルを書き換えるような式が仕込まれていても動かないよう、数の計算だけを許しています。

## 例

| 計算式 | 意味 |
|---|---|
| `値1 - 1` | 値1 より1つ前の番号 |
| `値1 * 53 / 100` | 0〜99 の値を、0〜52 に縮める（100 枚と 53 枚の連番をそろえる） |
| `math.max(値1, 値2)` | 値1 と値2 の大きいほう |
| `math.floor(値1 / 10)` | 値1 の十の位 |
| `値1 % 10` | 値1 の一の位 |

値の最大に合わせて画像を割り振るだけなら、計算式を書かずに [連番スロット（ゲージ）](連番スロット（ゲージ）) を使えます。

## 条件で出し分ける

比較と `and` `or` を組み合わせると、条件によって結果を変えられます。

```
条件 and 条件が成り立つときの数 or 成り立たないときの数
```

| 計算式 | 意味 |
|---|---|
| `値1 < 30 and 1 or 0` | 値1 が 30 未満なら 1、そうでなければ 0（HP が減ったら、ピンチの顔の画像に切り替える） |
| `値1 == 0 and -1 or 値2` | 値1 が 0 なら -1（範囲外の扱いが「表示しない」なら何も出さない）、そうでなければ値2 |
| `値1 >= 100 and 2 or (値1 >= 50 and 1 or 0)` | 100 以上なら 2、50 以上なら 1、それより小さければ 0 |

- 比較だけ（`値1 < 30`）の結果は数ではないので、「計算式の結果が数になりません」の案内が出ます。`and` と `or` で数にしてください。
