> 対象：v0.3.0

## 画像が出ない

設定に不備があると、プレビューに `[連番まとめ]` で始まる案内が出ます（土台の「案内の表示」が「選択中だけ」なら、土台を選んでいる間だけ）。

| 案内 | 原因と直し方 |
|---|---|
| フィルタ効果「連番スロット」などを追加してください。 | 土台にスロットが付いていません。オブジェクト設定の [+] →「連番まとめ」から追加します |
| スロットに、連番の画像を設定してください。 | スロットの「画像」が空です |
| 選んだ画像が見つかりません：… | 画像を移動・改名した可能性があります。選び直します |
| 連番として扱えないファイル名です：… | ファイル名の拡張子の直前に番号がありません（例：`hp_000.png` のように番号をつける） |
| この土台には「…」がありません。 | スロットが従う値を、この土台が持っていません |
| この土台は「…」のスロットに対応していません。 | 新しい版のスロットを、古い版の土台に付けた可能性があります。版をそろえます |
| 計算式が空です。 | 計算式を入れます |
| 計算式を計算できません：…（…） | 使えない名前や記号があります。括弧の中の理由と、[計算式の書き方](計算式の書き方) を見ます |
| 計算式を読めません：… | 括弧の数などが合っていません |
| 計算式の結果が数になりません：… | 0 で割るなどして、数にならない結果になっています |

案内が出ないのに画像が出ないときは、表示する番号が連番の範囲を外れています。「範囲外の扱い」と「枚数」を見直します（[連番スロット](連番スロット)）。

## 中間点が効かない

移動方法が「直線移動(時間制御)」「補間移動(時間制御)」だと、中間点の時間が無視されます。「直線移動」にしてください。

## 値ごとに違うタイミングで動かせない

8つの値と、スロットの X・Y・拡大率は、同じ中間点を共有します。値ごとに違うタイミングで動かしたいときは、土台を分けます。
